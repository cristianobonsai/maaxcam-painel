# Usuários: Grupos de acesso

Os **grupos de acesso** definem **quais câmeras cada convidado enxerga**. Em vez de marcar câmera por câmera para cada pessoa, você monta um grupo (por exemplo, "Equipe da loja"), coloca as câmeras nele e escolhe quem pode ver. Um convidado enxerga a **soma** de todos os grupos dele mais as liberações avulsas. Nas imagens, os números vermelhos indicam onde você deve olhar ou clicar.

Para chegar aqui, abra **Usuários** no menu e clique na aba **Grupos de acesso**. Só o dono da conta vê essa tela.

## 1. A aba Grupos de acesso

![Aba Grupos de acesso com o campo para criar grupo e a lista de grupos](img:usuarios-grupos-acesso-01-lista)

1. Digite o nome do novo grupo (**1**), por exemplo "Equipe da obra", e clique em **Criar grupo** (**2**). O grupo novo abre na hora para você escolher as câmeras e as pessoas.
2. **Ajuste fino por convidado** (**3**) libera câmeras avulsas para uma pessoa (item 3).
3. **Resumo de acessos** (**4**) mostra o que cada convidado enxerga (item 4).
4. Cada grupo aparece numa linha (**5**) com a quantidade de câmeras e de pessoas. Clique nela para editar.

Se você ainda não tem convidados, o painel avisa para convidar alguém primeiro, na aba **Usuários**.

## 2. Editar um grupo

![Tela de um grupo com as câmeras, as pessoas e o botão Salvar grupo](img:usuarios-grupos-acesso-02-editar-grupo)

Dentro do grupo:

1. Em **Câmeras deste grupo** (**1**), marque as câmeras. Use **Buscar câmera** se tiver muitas.
2. Em **Quem vê este grupo** (**2**), marque cada pessoa que deve enxergar essas câmeras. **Sem ninguém marcado, o grupo não libera acesso a ninguém.**
3. Clique em **Salvar grupo** (**3**). Aparece "✓ Salvo".

Para apagar o grupo, clique em **Excluir grupo** (**4**) e confirme com **Sim**. As câmeras não são apagadas; só deixam de ser liberadas por esse grupo. Use **‹ Voltar** para retornar à lista.

## 3. Ajuste fino por convidado

![Liberação de câmeras avulsas para um convidado](img:usuarios-grupos-acesso-03-ajuste-fino)

Quando uma pessoa precisa de uma câmera a mais, sem criar um grupo só para isso:

1. Escolha o convidado (**1**).
2. As câmeras que ele **já vê por um grupo** aparecem marcadas e bloqueadas, com o aviso "já vê pelo grupo" e o nome do grupo (**2**).
3. Marque as câmeras avulsas que você quer liberar (**3**).
4. Clique em **Salvar liberações** (**4**).

## 4. Resumo de acessos

![Resumo com todas as câmeras que o convidado enxerga](img:usuarios-grupos-acesso-04-resumo)

O **Resumo de acessos** é só para conferir: para cada convidado (**1**), lista todas as câmeras que ele enxerga, somando grupos e liberações avulsas. Se aparecer "Nenhuma câmera liberada ainda", a pessoa não está em nenhum grupo e não tem liberação avulsa.
